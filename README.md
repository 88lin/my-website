# 88lin · 茉灵智库 ✦

我的个人网站 — 一个 AI 研究者与 Agent 工程实践者的「桌面 OS」风格互联网小家。

## 体验方式

- **首页**：MacBook 终端开机动画 → 回车进入 → 深空桌面 OS（可拖拽窗口 / 图标 / 贴纸，菜单栏时钟）
- **作品集**：`1 Person + AI = 1 Team` 工作流 + 开源项目 / Agent Skills / 站点矩阵 / 写作分享
- **数字花园**：无限画布 —— 滚动缩放、拖拽、连线、图层与撤销，记录这个花园的一切
- **告别区**：滚动到底，桌面收进 MacBook，`cat contact.md` 留个联系方式，循环再会

## 关于

这里是「88lin / 茉灵智库」的主页，把项目、站点、博客与分享整理成一站式入口。

- **精选项目** — video_vip、lofi-radio-web、computer-repair-skill 等开源作品
- **站点矩阵** — 博客、导航站、维修技能站、Lofi Radio、深度研究
- **最新文章** — 来自 [茉灵智库博客](https://blog.88lin.eu.org) 的最新内容

## 技术栈

纯前端，零框架。HTML + CSS + Vanilla JS。

- `index.html` — 桌面 OS 主页（终端打字 → 缩放进入 → 窗口管理 → 退出动画）
- `canvas.html` — 无限画布数字花园

可直接部署在 GitHub Pages。
